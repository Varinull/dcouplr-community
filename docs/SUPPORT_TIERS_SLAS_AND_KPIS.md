## Support model

Community Core is free and self-service:

| Attribute | Community Core |
| --- | --- |
| **Price** | $0 (Apache 2.0) |
| **Capacity** | 1 local CLI / agent on your machine |
| **Intake** | [GitHub Issues](https://github.com/Varinull/dcouplr-community/issues) and Discussions |
| **Response** | Best effort (volunteer / community) |
| **War-rooms / TAM / paid SLA** | Not included |

Commercial support channels, contractual SLAs, and paid capacity tiers are **not documented in this repository**. See [https://dcouplr.com](https://dcouplr.com) for commercial offerings.

---

## Before you open an issue

1. Run `dcouplr doctor` and paste the output (redact secrets).
2. Include a **sanitized** sample input (no private IPs, keys, or hostnames).
3. Name source format, target format, CLI version (`dcouplr version`), and OS.

---

## What we will not ask for

Community responders should never request production credentials, unredacted private network layouts, or access to internal governance consoles. Those surfaces are outside Community Core.
