# 🚀 `<dcouplr/>` Community Core Quickstart & Installation Guide

**Security Guarantee:** Zero-Egress In-VPC Volatile RAM Execution ($0 Data Egress)  
**License:** Apache License 2.0  
**Supported Platforms:** Linux (x86_64, aarch64), macOS (Apple Silicon, Intel), Windows (x64), Docker  

---

## 📑 Overview

`<dcouplr/>` is a local-first, zero-egress observability and infrastructure transpiler. It converts vendor-locked monitoring alert rules, telemetry dashboards, and cloud configurations into vendor-neutral OpenTelemetry, Prometheus, and OpenTofu/Terraform standards right inside your terminal or private VPC.

**Zero Network Egress:** Your infrastructure configs and proprietary queries never leave your machine ($Egress_{WAN} \equiv 0.00\text{ KB}$).

## 1. 💻 Installation

### Option 1: Linux & macOS One-Line Installer
```bash
curl -fsSL https://get.dcouplr.io | sh
```
*Or using the direct community repository script:*
```bash
curl -fsSL https://raw.githubusercontent.com/varinull/dcouplr-community/main/install.sh | bash
```

### Option 2: Windows PowerShell Installer
Run in PowerShell:
```powershell
irm https://get.dcouplr.io/install.ps1 | iex
```
*Or using the direct community repository script:*
```powershell
irm https://raw.githubusercontent.com/varinull/dcouplr-community/main/install.ps1 | iex
```

### Option 3: Homebrew (macOS / Linux)
```bash
brew install varinull/tap/dcouplr
```

## 3. 🔄 Your First Transpilation

### Translating Datadog Alerts to Prometheus / Grafana
Save your source alert rule to `monitor.json`:
```json
{
  "name": "High CPU Load Alert",
  "type": "metric alert",
  "query": "avg(last_5m):avg:system.cpu.user{environment:production} > 85",
  "message": "CPU usage is above 85% on production host @pagerduty"
}
```

Run the transpiler:
```bash
dcouplr translate -i monitor.json -t grafana
```

Output:
```yaml
# Generated by <dcouplr/> Community Core (Apache 2.0)
# Zero-Egress AST Verification: PASS
groups:
  - name: high-cpu-load-alert
    rules:
      - alert: HighCPULoadAlert
        expr: avg_over_time(system_cpu_user{environment="production"}[5m]) > 85
        for: 2m
        labels:
          severity: critical
          environment: production
        annotations:
          summary: "High CPU Load Alert"
          description: "CPU usage is above 85% on production host"
```
